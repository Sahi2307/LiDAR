// 01 · CONTEXT

The problem.

Electrical utility poles are everywhere, but nobody has a complete picture of what's on them. Manual surveys are slow, expensive, and error-prone — a single district can require weeks of field visits and still produce records riddled with gaps.

PoleScan was built to change that using aerial LiDAR data that utilities already collect, turning a raw point cloud into a structured inventory of every pole, crossarm, transformer, and guy wire without a single truck roll.

// 02 · METHODOLOGY

The method.

We take every pole cluster and collapse it into a 2D side-view image, as if the pole were stamped flat against a sheet. In that 2D view the geometry is obvious — the vertical line is the shaft, a horizontal bar at 8m is a crossarm, a dense rectangle hanging off one side is a transformer.

Components are labeled in 2D using a small set of geometric rules (linearity, planarity, height-above-ground) and the labels are backprojected into the original 3D point cloud. This is the Poux methodology adapted for pole infrastructure — simple, fast, and explainable.

// 03 · STACK

The stack.

Data I/O →laspy, PDAL Ground filter →SMRF (Simple Morphological Filter) Detection →scipy cKDTree, sklearn DBSCAN Classification →Geometric rule engine (linearity, planarity, HAG) Backend →FastAPI (Python) Frontend →Leaflet.js, Vanilla JS Map tiles →OpenStreetMap (no API key)
